                                1. INTRODUCTION

1. Overview
Medicine Reminder and Health Tracker - CareSync is a comprehensive, modern, and
cross-platform personal healthcare and medication management system designed to
streamline patient adherence and empower family caregivers. Built with both patients
and caregivers in mind, CareSync digitizes medication schedules, vitals telemetry,
and dietary health, transitioning from error-prone manual paper logs to an efficient,
automated, and secure digital environment.

The software is accessible through a responsive Web Application, a dedicated Local
Desktop Application (Electron), and cross-device mobile browsers, ensuring seamless
access and timely reminders across all patient and caregiver devices.

2. Objectives
The primary objectives of the Medicine Reminder and Health Tracker - CareSync project are to:
Automate Medication Schedules: Simplify dosing timetables with multi-period scheduling,
Web Audio melodic alarms, and dosage instructions, reducing missed doses and human error.
Enhance Caregiver Oversight: Provide off-site family members and caregivers with real-time
telemetry, missed dose alerts, emergency SOS triggers, and direct communication shortcuts.
Track Health Vitals & Biomarkers: Offer a centralized logging and visual trend system
for Blood Pressure, Blood Glucose, Weight, BMI, and Temperature with clinical classification.
Integrate AI & Clinical Intelligence: Deliver tailored caloric blueprints via Google Gemini AI
and calculate age-specific preventive screening recommendations via a Python Bio-Chronology Engine.
Provide a Resilient Multi-Platform Experience: Deliver a synchronized user interface whether
accessed via Web browsers or the standalone offline-ready Desktop Application.

3. Key Features
Role-Based Persona Switcher: Distinct, tailored interfaces for Patients (simplified, high-contrast,
accessible controls) and Caregivers (remote oversight, alert feeds, and SOS management).
Smart Medication & Alarm Engine: Visual pill identification, custom reminder chimes (Web Audio API),
snooze/skip controls, adherence streak counters, and celebratory milestone confetti.
Clinical Vitals Analytics: Interactive Chart.js telemetry tracking Blood Pressure AHA stages,
fasting/postprandial glucose levels, weight trajectories, and automated BMI categorization.
Pharmacy & Refill Hub: Automated fuel-gauge pill stock counters, low-stock threshold warnings,
and a 1-click refill ordering simulator with order status tracking.
Digital Health Vault: Secure archiving and fullscreen inspection for prescriptions, doctor notes,
and medical laboratory diagnostic reports.
Gemini AI Nutrition & Python Bio-Engine: Interactive AI diet assistant for calorie/macro goals,
paired with a Python engine computing exact life span, zodiac, and life-stage health guidelines.
Visual Calendar & Visual Steppers: Accessible birth-date selection with decade-jumps and age presets.

4. Technology Stack
CareSync is developed using a robust, high-performance, and modern technology stack:
Backend Environment: Node.js (Express REST API) and Python 3.14 (Clinical Bio-Engine Microservice)
Frontend Environment: HTML5, CSS3 (Modular Tokens with 4 Custom Themes), Vanilla JavaScript, Chart.js
Database Architecture: Neon PostgreSQL (Serverless Cloud Relational Database with Connection Pooling)
AI Integration: Google Gemini AI API (Personalized Nutrition & Dietary Guidance)
Desktop Packaging: Electron (Cross-platform desktop executable with local asset bundling)
Audio & Alerts Engine: Web Audio API (Synthesized harmonic chimes) and Web Notification API
Hosting / Deployment: Vercel / Local Dev Server and GitHub Repository
