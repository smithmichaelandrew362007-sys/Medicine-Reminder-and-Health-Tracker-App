                              2. SYSTEM STUDY

HARDWARE REQUIREMENTS:

- Processor       : Intel Core i3 or equivalent (minimum)
- RAM             : 4 GB (minimum), 8 GB recommended
- Hard Disk       : 500 MB free disk space for application and local data
- Display         : Minimum 1024x720 resolution monitor or mobile screen
- Audio Output    : Built-in speakers or headphones (for Web Audio alarm chimes)
- Internet        : Required for Neon Cloud PostgreSQL mode; optional in offline mode

SOFTWARE REQUIREMENTS:

- Operating System : Windows 10/11 (Desktop App) or any OS with a modern browser
- Runtime          : Node.js v22 or later & Python 3.10+ (Bio-Engine)
- Web Browser      : Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari
- Desktop Shell    : Electron v44+ (included as devDependency)
- Database         : Neon Cloud PostgreSQL (production) or local storage
- Package Manager  : npm (bundled with Node.js)

TECHNOLOGY STACK:

- Backend          : Node.js, Express.js v5.3.0, Python microservice
- Frontend         : HTML5, CSS3 Design Tokens, Vanilla JavaScript, Chart.js
- Database Drivers : @neondatabase/serverless v1.2.0 (PostgreSQL)
- Artificial Intell: Google Gemini AI API (@google/genai v2.30.0)
- Authentication   : Node.js crypto module (scryptSync, timingSafeEqual)
- Audio & UI Assets: Web Audio API (Synthesized chimes), Canvas Confetti, Lucide
- Deployment       : Vercel (Web/Cloud), Electron Packager (Desktop executable)
